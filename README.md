# 花のつくり暗記ゲーム

理科の花のつくり（がく・花びら・おしべ・めしべの数）、虫媒花と風媒花の違い、花粉の形の見分け方を、クイズ形式で楽しく覚えるための静的Webアプリです。

## 特徴

- 8種類の花のカード学習（ジャガイモ・アブラナ・チューリップ・ハナショウブ・アサガオ・エンドウ・サクラ・タンポポ）
- 数字テスト、虫媒花・風媒花クイズ、花粉の形クイズ
- 全カテゴリを混ぜた「まとめテスト」
- 達成度の記録と、間違えた項目だけを出題する「苦手だけ出題」機能（ブラウザのlocalStorageに保存）
- 正解・不正解時の効果音と、毎回変わる応援メッセージ

## 使い方

`index.html` をブラウザで開くだけで動作します。外部ライブラリへの依存はありません。

GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で `main` ブランチ / ルートを指定してください。
